# Test-Driven Development (TDD) Workflow

1. **Write Test First (RED)**: Write unit and integration tests describing the desired behavior before touching production code.
2. **Run Tests**: Verify that the new tests fail for the expected reason.
3. **Implement Minimum Code (GREEN)**: Write only the code required to make tests pass (Simplicity First).
4. **Refactor**: Clean up duplication and naming while keeping all tests green.
5. **Coverage Gate**: Enforce 80%+ branch and function coverage.
